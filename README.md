# EduManage AI V5 Premium

Ứng dụng quản lý chuyên môn đa điểm trường – Trường Tiểu học Đỗ Thúc Tịnh.
Một file HTML duy nhất, dữ liệu mẫu lưu trên trình duyệt, không cần máy chủ.

## Xem trực tiếp
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới, tải toàn bộ file trong gói này lên (gồm cả `.nojekyll`).
2. Vào **Settings → Pages**, chọn nhánh `main`, thư mục `/ (root)`, nhấn **Save**.
3. Sau ít phút, trang chạy tại `https://<tên-tài-khoản>.github.io/<tên-repo>/`.
